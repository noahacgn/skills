# RESOURCES.md 格式规范

`RESOURCES.md` 是针对该主题精心筛选的可信来源集合。讲解所需的知识应直接从这里获取，而非依赖模型的参数化猜测。智慧与实践见解则源于此处列出的社区。

## 结构示例

```md
# {主题} 学习资源

## 知识来源 (Knowledge)

- [书籍: 《力量训练的科学与实践》 — Zatsiorsky & Kraemer](https://example.com)
  关于动作编排与身体适应的奠基之作。适用于：任何与周期化训练、恢复、强度区间相关的内容。
- [文章: "我应该练多少容量？" — Greg Nuckols (Stronger By Science)](https://example.com)
  基于循证医学的训练容量地标综述。适用于：每个肌群的每周训练组数目标制定。

## 实践见识与社区 (Wisdom / Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  高信息密度的 Subreddit，对伪科学有严格的版规过滤。适用于：训练计划评审、平台期问题排查。
- 本地活动: 每周二 {健身房名称} 的力量公开课
  适用于：获取关于动作举重姿态的实时指导与反馈。
```

## 编写规则

- **仅收录高信任度来源。** 优先选择一手文献、公认专家、同行评审研究以及具备良好管理秩序的社区。若某项资源实质上是披着教学外衣的营销推广，请将其剔除。
- **为每条条目添加注释。** 纯粹的链接在三个月后将毫无用处。附加一行说明：它涵盖了什么内容，以及何时应当查阅它。
- **按“知识 (Knowledge)”与“见识/社区 (Wisdom)”分组。** 呼应 [SKILL.md](./SKILL.md) 中的教学哲学。某个资源只出现在其中一个分组是完全正常的。
- **明确标明知识空白。** 若使命所需的某个领域尚无优质资源，添加一个 `## 知识盲区 (Gaps)` 小节列出缺失的内容，以指引未来的搜索方向。
- **果断精简。** 若某项资源被证实错误、肤浅或偏离使命，应当将其彻底删除，而非隐藏在角落。五个精辟敏锐的来源远胜于三十个平庸的来源。
- **记录社区参与偏好。** 若用户明确表示不希望加入社区，请在此处注明，以便后续会话不再反复推荐。
