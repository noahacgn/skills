# 杂项工具 (Misc)

保留留存但较少使用的工具，未在插件中正式推广。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：配置 Claude Code 钩子（Hooks），在危险的 Git 命令（push、reset --hard、clean 等）执行前对其进行拦截。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：将测试文件中的 `as` 类型断言迁移替换为 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：自动生成包含章节、练习题、参考解答与概念讲解的练习目录脚手架。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：配置集成了 lint-staged、Prettier、类型检查与测试套件的 Husky pre-commit 钩子。
