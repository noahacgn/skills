# 分类定级标签映射表 (Triage Labels)

技能体系基于五种规范的分类定级角色展开。本文档将这些角色映射到本仓库 Issue 追踪系统所使用的实际标签字符串。

| mattpocock/skills 规范标签 | 当前追踪系统中的实际标签 | 含义说明 |
| -------------------------- | ------------------------ | -------- |
| `needs-triage`             | `needs-triage`           | 维护者需要评估此 Issue |
| `needs-info`               | `needs-info`             | 等待提交者补充更多信息 |
| `ready-for-agent`          | `ready-for-agent`        | 规格明确完备，可供 AFK 离线 Agent 接手 |
| `ready-for-human`          | `ready-for-human`        | 需要由人类工程师亲自实现 |
| `wontfix`                  | `wontfix`                | 明确拒绝，不予处理 |

当某项技能提及某个角色时（例如“应用已就绪可供离线 Agent 接手的标签”），请使用本表右侧对应的实际标签字符串。

用户可直接编辑右侧列以匹配当前团队实际使用的标签命名。
