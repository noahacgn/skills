# 阶段边界规范 (Phase boundaries)

**阶段 (phase)** 是会话内部的一段完整工作——深度盘问、代码实现、质量验收（QA）。此处的定义故意保持一定弹性：当你心中产生*“好的，这部分搞定了”*的念头时，一个阶段便告结束。

**阶段边界 (phase boundary)** 是两个阶段之间的过渡缝隙，也是做出上下文治理决策的唯一合理时刻。在阶段进行中无需做出决策——要么继续推进，要么将剩余工作拆分给子 Agent。在阶段进行中压缩上下文会导致 Agent 丧失推理主线。

## 五种选择方案

| 选项 | 作用与机制 |
| ---- | ---------- |
| **继续 (Continue)** | 留在当前会话中。完全无上下文切换开销。 |
| **`/clear`** | 清空上下文窗口，从零开始全新对话。 |
| **`/handoff`** | 编写可移植的 Markdown 文件，并在任何环境中以此为种子启动会话。 |
| **子 Agent (Subagent)** | 将具体任务派发至其独立的上下文窗口，并获取汇总报告。 |
| **`/compact`** | 压缩当前上下文，并使用提炼出的摘要作为全新会话的种子。 |

## 决策树 (The tree)

在阶段边界处自顶向下依序判断。以第一个得出**“是 (yes)”**的选项为准。

**1. 能否在当前会话中继续推进？** 满足以下两点之一即判定为“是”：下一阶段需要将本阶段作为**一手来源 (primary source)** 完整参考，或者当前窗口内剩余的[聪明区 (smart zone)](https://www.aihero.dev/ai-coding-dictionary/smart-zone)空间（约 15 万 Token）足以容纳下一阶段。深度盘问 → 代码实现是典型的肯定场景：实现阶段需要逐字逐句参考先前的推理过程，而非一份二手摘要。“继续”零成本且零信息损失，因此在考虑其他方案之前，首先尝试排除其他选项而选择“继续”。

**2. 既有上下文是否与后续任务完全无关？** 当前会话中的全部内容——探索过程、中间决策、碰壁死胡同——是否均可彻底废弃？若是，选择 **`/clear`**。这是棋盘上成本最低的一步：耗时为零，并能全量归还整个上下文窗口。`/clear` 同样是非终结性的——旧会话随时可以重新恢复。

做错此判断的代价是单向不可逆的。若清空了*具有高度相关性*的上下文，你将永久失去所构建代码背后的**决策缘由 (why)**，后续即便反复阅读 Diff 也无法将其完整还原。

**3. 是否需要进行交接移交？** `/handoff` 的适用范围非常狭窄。只有在满足以下场景时才需要它：

- 切换到**全新的宿主工具环境**（如 Claude → Codex），
- 移动到**全新的目录**或仓库，
- 将工作交付给**同事**，
- 或在**阶段进行中**分叉出意外发现的旁支任务，且不希望打乱当前主线。

上述清单已穷尽其适用范围。`/handoff` 所买到的是**可移植性 (portability)**——一份可以流转的文件。如果没有任何内容需要跨边界流转，你根本不需要它。

**4. 该任务能否在离线/离开键盘 (AFK) 状态下完成？** 任务边界是否界定得足够清晰，以至于无需你的实时把关与干预即可自主运行？若是，将其派发给**子 Agent (subagent)**，保持当前主会话不受污染。自动化代码审查是标准案例：Agent 阅读 Diff 并汇总汇报，在其执行期间完全不需要人类介入。

**5. 否则，执行 `/compact`。** 具有相关上下文、相同的工具环境、相同的目录，且你依然需要保持在反馈闭环中——决策树最终便会落在此处，且在日常开发中非常高频。压缩时附带具体的引导指令（例如 `/compact 我们接下来要对这个模块进行 QA 验收`），以便让摘要重点保留下一阶段所需的关键信息。

`/compact` 是**兜底选项，而非首选动作**。它位于决策树的最底部，因为排在其上方的四个问题要么成本更低，要么更为精准。一上来就盲目压缩的典型失效模式是：启动的全新会话会对摘要中被抹平省略的某项决策表现出极度自信的误判。

## 一手来源与二手来源 (Primary and secondary sources)

除**继续 (Continue)** 外，每一种操作都会将**一手来源**退化为**二手来源**——原本原汁原味发生的完整会话，被替换为一份浓缩摘要。其权衡规律始终如一：

| 来源类型 | 信息完整度 | 噪音水平 | 调整回旋空间 |
| -------- | ---------- | -------- | ------------ |
| 一手来源 (Continue) | 完整无损 | 较多 | 较小 |
| 二手来源 (`/compact`, `/handoff`) | 有损浓缩 | 较少 | 充裕 |

这正是必须优先评估第 1 个问题的原因。只有当留在当前会话的开销超出其保真收益时，才值得承受这种信息有损。

## 权衡在于主观判断 (Judgement calls)

这些判断并非绝对客观——每一项都包含品味与权衡，同一个边界在不同的场景下可能做出不同的选择。核心价值在于**按顺序**提出这些问题，并严格在阶段边界处决策，而非在工作进行到一半时仓促应对。
