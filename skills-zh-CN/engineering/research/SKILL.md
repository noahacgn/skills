name: research
description: 针对高信任度的一手来源深入调研某个问题，并将调研成果作为 Markdown 文件留存在仓库中。当用户希望调研某个主题、收集文档或 API 事实、或将阅读调研工作委派给后台 Agent 时使用。
---

启动一个**后台子 Agent** 来执行调研，以便在你继续工作的同时它在后台阅读分析。

如果你当前已经在作为后台 Agent 运行，不要再分发新的子 Agent；直接由你自己执行调研。

其核心职责：

1. 针对**一手来源**（官方文档、源代码、规格标准、官方第一方 API）开展问题调研——而非二手转述。追溯每条论断至其背后的权威来源。
2. 将调研成果整理为单篇 Markdown 文档，清晰注明每个结论的引用来源。
3. 将文件保存在仓库既有存放此类调研笔记的位置；契合既有约定，若尚无约定，存放在合理位置并明确告知用户路径。
